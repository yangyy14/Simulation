# 智能定投使用 PE 百分位 + 离散档位

智能定投以 PE（滚动市盈率）历史百分位作为估值标尺，通过 3 档离散倍率将估值映射为定投金额。黄金使用价格百分位替代。

**Why**: PE 百分位反映了"同等的盈利能力，当前的价格处于什么水位"，相比均线偏离或价格分位，它不会被企业盈利自然增长误判为"变贵"。离散档位简单、可解释，和市面上基金 App 的智能定投行为一致，用户能直观理解"便宜时多买"的具体含义。连续公式在极端估值下金额波动过大，不如离散方案稳健。

**Considered Options**: (a) 价格百分位——将正常盈利增长误判为变贵；(b) 均线偏离——技术指标，无法区分业绩驱动涨跌和情绪驱动涨跌；(c) 连续公式——PE=8 倍时金额翻数倍，超出用户承受范围。

**Key decisions**:
- 回溯窗口 10 年（不足 10 年时用实际可用年数）
- 默认 3 档：PE ≤ 30% → 1.5×，30%-70% → 1.0×，≥ 70% → 0.5×；用户可调
- 倍率范围 0.1× ~ 5×，档位重叠时报错
- 每个 Segment 独立选择 fixed/smart 模式
- PE 数据与价格数据存储在同一 CSV 第三列
