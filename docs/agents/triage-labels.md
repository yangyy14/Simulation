# 分类标签

技能内部使用五个标准分类角色。此文件将这些角色映射到本仓库实际使用的状态字符串。

| 标准角色              | 本仓库状态      | 含义                       |
| --------------------- | --------------- | -------------------------- |
| `needs-triage`        | `待评估`        | 维护者需要评估此问题       |
| `needs-info`          | `待补充信息`    | 等待回复者补充更多信息     |
| `ready-for-agent`     | `可自动处理`    | 规格完整，Agent 可自行处理 |
| `ready-for-human`     | `需人工处理`    | 需要人工实现               |
| `wontfix`             | `不修复`        | 不会执行                   |

当技能提到某个角色时（如"打上可自动处理标签"），使用本表中对应的状态字符串。
