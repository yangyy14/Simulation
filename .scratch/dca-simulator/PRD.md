# PRD：定投收益模拟工具

Status: 可自动处理

## Problem Statement

投资者想评估一个定投策略在历史上的真实表现。例如：2010 至 2020 每月定投沪深 300 指数 1000 元、然后 2016 至 2025 每月定投中证 500 指数 2000 元，至今累计赚了多少？年化回报是多少？目前没有轻量工具能让你自由组合多个指数、多个时间段的定投策略，即时看到历史回测结果。

## Solution

一个纯前端的定投收益模拟 Web 工具。用户在页面上配置定投策略（一至多个可重叠的片段，每片段指定指数、金额、频率、时间段），页面即时计算并展示：期末市值、累计投入、累计收益率、XIRR 年化收益率，同时用市值 vs 成本曲线图和明细表格呈现全部数据。策略可导出为 JSON 文件、编码到 URL 分享链接，或自动保存在浏览器中。

## User Stories

1. 作为一名投资者，我想选择多个指数（如上证 50、沪深 300、中证 500、中证 1000、中证红利、黄金），为每个指数独立设置定投金额和时段，以便比较不同组合的历史表现。
2. 作为一名投资者，我想设置定投的开始和结束日期，定投频率（按月或按周），以及每月或每周的具体定投日，以便模拟真实的定投节奏。
3. 作为一名投资者，我想让定投结束后的持仓继续保留至计算窗口结束，以便看到持仓观望阶段的市值变化。
4. 作为一名投资者，我想在一个策略中对同一指数在不同时段设置不同的定投金额（如早期月投 1000，后期月投 2000），以便模拟收入增长后的策略调整。
5. 作为一名投资者，我想在不同时段定投不同指数（如 2010-2015 投沪深 300，2016-2022 投上证 50），并将持仓累积计算跨周期的总收益。
6. 作为一名投资者，我想看到期末总市值、累计投入总额、累计收益率和 XIRR 年化收益率四个核心指标，以便全面评估策略表现。
7. 作为一名投资者，我想看到市值随时间变化的曲线图，并能对比投入成本线，以便直观判断何时开始盈利。
8. 作为一名投资者，我想用鼠标悬停在图表上时看到该位置的具体数据（日期、市值、成本、收益率），以便精确查看每个时间点的状态。
9. 作为一名投资者，我想看到每笔定投的明细表格（日期、指数、买入净值、买入份额、当前市值、盈亏），以便核对计算明细。
10. 作为一名投资者，我想手动输入申购费、赎回费、管理费率（默认均为 0），以便模拟真实交易成本对收益的影响。
11. 作为一名投资者，我想我的策略能自动保存在浏览器中，关闭页面再打开时配置不丢失。
12. 作为一名投资者，我想将策略导出为 JSON 文件，发送给别人或存档。
13. 作为一名投资者，我想导入别人分享的 JSON 策略文件，直接看到结果。
14. 作为一名投资者，我想将我的策略生成一个分享链接，发送给别人后对方打开链接就能看到一模一样的策略和结果。
15. 作为一名投资者，我想在手机和桌面端都能正常使用这个工具。
16. 作为一名投资者，当我的定投日恰逢节假日或周末时，系统应自动顺延到下一个交易日执行，以便模拟真实基金扣款行为。
17. 作为一名投资者，我想看到每个定投片段以卡片形式展示，能自由添加或删除片段。

## Implementation Decisions

### 架构：纯前端

React + TypeScript + Vite。无后端、无数据库。历史指数数据以 CSV 文件形式存放在 `public/data/` 下，前端启动时按需加载。XIRR 计算、现金流生成、组合估值全部在浏览器中完成。

### 数据源：全收益指数

使用中证指数有限公司发布的全收益指数（Total Return Index）作为标的物价格基准。全收益指数将成分股现金分红再投资计入指数序列，与定投红利再投资设定一致。不使用具体基金产品的净值，避免引入费率、跟踪误差等偶然因素。黄金使用上海金交所 AU9999 收盘价。数据由开发者手动准备为 CSV 文件，每个标的物一个文件。

背景：见 ADR-0001。

### 定投日顺延规则

当用户指定的定投日（如每月 1 日）恰好为非交易日时，自动顺延至下一个有数据的交易日。CSV 文件包含全部交易日数据，前端通过查询 dataLoader 实现顺延。

### 片段式策略模型

策略由若干独立的定投片段（Segment）组成。每个片段定义一段时间内对某个指数的定投规则：指数、频率（月/周）、定投日、金额、时间范围。所有片段的买入记录汇总到统一的现金流池中计算 XIRR 和总市值。片段允许时间重叠，允许在不同时段定投不同指数。

背景：见 ADR-0002。

### 计算窗口

用户可设置计算窗口的开始日期和结束日期。计算窗口的结束日期允许超出最后一个定投片段的结束日期——超出部分视为纯持仓观望（不定投也不卖出）。

### 费率模型（可选）

三种费用均为可选，默认值 0：
- 申购费：每次定投时按金额比例扣除
- 赎回费：计算期末市值时按比例扣除
- 管理费：按年化比例影响净值（从持有期的复权净值中扣除）

### 收益指标

- 累计投入总额 = Σ(每次定投金额 × (1 + 申购费率))
- 期末总市值 = Σ(每笔定投所获份额 × 计算窗口结束日的全收益指数值) × (1 - 赎回费率)
- 累计收益率 = (期末总市值 - 累计投入总额) / 累计投入总额
- XIRR：扩展内部收益率，将全部现金流按实际发生日期折现，Newton 迭代法求解使 NPV = 0 的年化折现率

### 模块划分

| 模块 | 类型 | 说明 |
|------|------|------|
| XIRR Calculator | Deep | 纯函数，输入现金流数组，输出年化利率 |
| Data Loader | Deep | 解析 CSV 为 PriceSeries 对象，提供顺延查询 |
| Strategy Engine | Deep | 策略验证 + 生成现金流 + 计算组合汇总 |
| URL Serializer | Deep | Strategy 对象与 URL 字符串的双向转换 |
| Storage | Shallow | localStorage 读写、JSON 导出导入 |
| UI Components | Shallow | React 组件，shadcn/ui + ECharts |
| App Shell | Shallow | 响应式布局、状态编排 |

### 首批标的物

上证 50 全收益、沪深 300 全收益、中证 500 全收益、中证 1000 全收益、中证红利全收益、AU9999（上海金交所 9999 金价收盘价）。

### 数据文件格式

每个标的物一个 CSV 文件，存放于 `public/data/`，格式：

```
日期,收盘价
2004-01-02,1000.25
2004-01-05,1003.18
```

日期为 ISO 8601 格式。包含全部交易日数据（约 5500 行/文件）。

### V2 预留

片段中的定投金额字段设计时预留策略接口（当前为固定金额，未来允许传入估值-金额映射函数），以支持智能定投（高价少买、低价多买）。

## Testing Decisions

### 测试策略

仅测试对外部行为，不测试实现细节。每个深模块的测试通过其公开接口验证。

### 被测试模块

1. **XIRR Calculator**：手动验算已知 Excel XIRR 结果（与 Excel `XIRR()` 函数输出对照）；验证空现金流、单笔现金流等边界情况。
2. **Strategy Engine**：给定 Mock PriceSeries 和已知策略，验证生成的现金流数量、金额、日期正确；验证投资组合汇总市值与手算结果一致。
3. **Data Loader**：用少量 CSV 行构造样本数据，验证日期解析、顺延逻辑（传入非交易日日期、周末日期，验证返回正确交易日）。
4. **URL Serializer**：Round-trip 编码-解码测试，验证策略对象在编码为 URL 再解码后与原对象等价。

### 不做端到端测试

UI 组件和 App Shell 通过浏览器实际使用验证，不编写自动化 UI 测试。

## Out of Scope

- 智能定投（基于估值高低自动调整金额）—— 属于 V2
- 真实基金产品的申购/赎回接口
- 用户账户系统
- 实时行情或运行时数据抓取
- 多币种支持
- 通胀调整
- 组合再平衡模拟
- 税务模拟
