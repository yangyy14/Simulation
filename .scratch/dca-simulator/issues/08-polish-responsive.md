## What to build

全应用打磨，确保在各种条件和设备下体验完整。

**响应式打磨**：
- 375px（小手机）、768px（平板）、1024px（小桌面）、1440px（大桌面）四个断点测试通过
- 移动端配置面板默认折叠为「展开配置」按钮（当前 Issue 05 已实现堆叠布局，此 issue 补折叠交互）
- 明细表在窄屏下横向滚动，不撑破布局
- 图表在窄屏下适当缩小高度

**加载态**：
- CSV 数据加载中，结果区显示 Skeleton 占位（KPI 卡片骨架 + 图表区域骨架 + 表格骨架）
- 加载完成后骨架淡出，结果淡入

**空状态**：
- 未配置任何定投片段时，结果区显示引导提示：「添加一个定投片段开始模拟」

**错误处理**：
- CSV 文件加载失败时，对应指数在 Select 中显示为不可用（灰色 + 提示「数据加载失败」）
- 当选中不可用指数时，结果区显示错误提示而非崩溃

**无障碍**：
- 所有交互元素有可见的 focus 环
- Tab 顺序符合视觉顺序
- Icon-only 按钮均提供 aria-label
- `prefers-reduced-motion` 受尊重（关闭过渡动画）

## Acceptance criteria

- [ ] 375px 宽度：无横向滚动，所有内容可见
- [ ] 768px 宽度：配置面板和结果区合理排布
- [ ] 1024px / 1440px：左右分栏比例正确
- [ ] 移动端配置面板可折叠
- [ ] CSV 加载时显示 Skeleton
- [ ] 无片段时显示空状态引导
- [ ] CSV 加载失败不导致白屏
- [ ] 键盘可访问所有交互元素
- [ ] prefers-reduced-motion 时动画禁用
