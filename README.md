# 定投收益模拟

基于真实历史数据的定投回测工具。支持多指数、多时段组合定投，支持基于 PE 估值的智能定投，计算累计收益率和年化回报率（XIRR）。

## 功能

- **多指数定投**：上证 50、沪深 300、中证 500、中证 1000、中证红利、黄金（AU9999）
- **灵活配置**：支持多片段组合，每个片段可独立设置指数、金额、频率（月/周）、时间范围
- **智能定投**：基于 PE 百分位自动调整金额——便宜时多买、贵时少买。用户设定两个阈值：PE ≤ a% 投 N 倍，PE ≥ b% 投 M 倍，中间正常 1.0×（见 ADR-0003）
- **费率模拟**：申购费、赎回费、管理费（年化）均可选配
- **全景图表**：市值 vs 成本走势图（含回本节点标记 + 可选 PE 分位参考线），支持缩放和悬停数据
- **交易明细**：每笔定投的日期、净值、份额、市值、盈亏，可排序
- **策略持久化**：localStorage 自动保存，JSON 文件导出/导入，URL 分享链接
- **数据审查页**：对比每个指数的价格指数与全收益指数走势 + PE 历史走势（含 30%/70% 分位参考线）
- **响应式**：桌面左侧配置面板 + 右侧结果，手机上下堆叠

## 计算过程

### 1. 定投日生成

对每个定投片段，按频率生成所有定投日期：

- **按月**：在 [开始日期, 结束日期] 内，每月 `day` 号生成一条记录
- **按周**：在 [开始日期, 结束日期] 内，每周的指定星期几（0=周日 … 6=周六）生成一条记录

### 2. 非交易日顺延

生成的定投日可能为非交易日（周末、节假日）。对每个日期，在 CSV 数据中查找 ≥ 该日期的第一个有记录的交易日。若超出数据范围则跳过。

### 3. 智能定投金额（可选）

若片段开启智能定投模式，先用 PE 历史百分位计算金额倍率 $M$：

- 查询定投日的 PE 值 $E$
- 回溯过去 $N$ 年（默认 10 年）的 PE 历史序列
- 计算 $E$ 在历史序列中的百分位（低于 $E$ 的值占比）
- 若百分位 ≤ 便宜阈值 $a$（默认 30%）→ $M = M_{\text{cheap}}$（默认 1.5）
- 若百分位 ≥ 昂贵阈值 $b$（默认 70%）→ $M = M_{\text{expensive}}$（默认 0.5）
- 否则 $M = 1.0$

黄金无 PE，用价格百分位替代。

### 4. 逐笔买入

设第 $i$ 笔定投：

| 变量 | 含义 |
|------|------|
| $A_i$ | 用户设定的定投金额（智能模式为基准金额） |
| $M_i$ | 智能定投倍率（固定模式 = 1.0） |
| $f_p$ | 申购费率 |
| $P_i$ | 顺延后交易日对应的指数价格 |
| $S_i$ | 买入份额 |

$$S_i = \frac{A_i \cdot M_i \cdot (1 - f_p)}{P_i}$$

### 5. 累计投入总额

$$\text{总投入} = \sum_i A_i \cdot M_i$$

### 6. 期末总市值

设 $f_r$ 为赎回费率，$f_m$ 为年化管理费率，$T_i$ 为第 $i$ 笔买入到计算窗口结束日期的持有年数，$P_{\text{end}}$ 为计算窗口结束日顺延后的指数价格：

$$M_i = S_i \cdot P_{\text{end}} \cdot (1 - f_m)^{T_i}$$

$$\text{总市值} = \left(\sum_i M_i\right) \cdot (1 - f_r)$$

管理费以复利方式按持有年数折减每笔份额的价值，赎回费在汇总后一次性扣减。

### 7. 累计收益率

$$\text{累计收益率} = \frac{\text{总市值} - \text{总投入}}{\text{总投入}}$$

### 8. XIRR 年化收益率

XIRR 将每一笔现金流按实际发生日期折现，求解使净现值为零的年化折现率 $r$：

$$\sum_{i=1}^{n} \frac{C_i}{(1 + r)^{(t_i - t_1)/365}} = 0$$

其中 $C_i$ 为现金流（投入为负，终值为正），$t_i$ 为发生日期。使用 Newton-Raphson 迭代法求解，收敛阈值 $10^{-6}$。

**示例**：每月投 1000 元，投 2 笔，期末市值 2300 元：

| 日期 | 现金流 | 说明 |
|------|------|------|
| 2024-01-01 | -1000 | 第 1 笔定投 |
| 2024-07-01 | -1000 | 第 2 笔定投（半年后）|
| 2025-01-01 | +2300 | 期末赎回 |

$$-1000 + \frac{-1000}{(1 + r)^{0.5}} + \frac{2300}{(1 + r)^{1}} = 0$$

解得 $r \approx 20.5\%$。累计收益率仅 15%，但 XIRR 更高是因为第一笔钱放了一整年、第二笔只放了半年——XIRR 考虑了资金的时间权重。

## 为什么用全收益指数

**价格指数**仅反映股价涨跌，不含分红。当成分股除息时，价格指数会随之跳空下跌。

**全收益指数**将每次分红按除息日价格虚拟买回同一股票，消除了除息缺口。

详见 `CONTEXT.md` 和 `docs/adr/0001-total-return-index.md`。

## 技术架构

```
src/
├── modules/              ← 深模块（纯逻辑，可独立测试）
│   ├── xirr.ts            XIRR 计算（Newton 迭代法）
│   ├── data-loader.ts     CSV 解析（价格 + PE）+ 顺延查询
│   ├── strategy.ts        定投引擎（现金流生成 + 组合估值 + 智能模式）
│   ├── valuator.ts        PE 百分位计算 + 估值→倍率映射
│   └── url-serializer.ts  策略 ↔ URL 编码
├── components/           ← 浅模块（React UI）
│   ├── ConfigPanel.tsx    配置面板（计算窗口、费率、片段编辑）
│   ├── SegmentEditor.tsx  定投片段表单（含智能定投 UI）
│   ├── KpiCards.tsx        收益指标卡片
│   ├── ValueChart.tsx      ECharts 市值 vs 成本 + PE 辅助线
│   ├── TransactionTable.tsx  定投明细表格（逐笔精算市值）
│   └── DataExplorer.tsx   数据审查页（价格/全收益对比 + PE 走势）
├── hooks/
│   └── useAutoSave.ts     localStorage 自动保存
└── App.tsx               应用壳（状态管理、路由、布局）
```

React 18 + TypeScript + Vite。纯前端，无后端、无数据库。51 个 Vitest 单元测试覆盖全部深模块。
