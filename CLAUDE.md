## Architecture

Five deep modules (testable in isolation, no UI dependencies):

| Module | Responsibility |
|--------|---------------|
| **XIRR Calculator** | Pure function: `(cashflows: {date, amount}[]) => number`. Newton's method, convergence 1e-6. |
| **Data Loader** | Parses CSV from `public/data/` into `IndexData`. Provides `getPrice(date)` with roll-forward for non-trading days. `getMetric(date)` returns PE for stocks, price for gold. `getMetricsInRange()` for historical PE sequences. Stock CSV has 3 columns `日期,收盘价,市盈率`; gold has 2. |
| **Strategy Engine** | Validates Strategy, generates buy transactions via cashflow generation, calculates portfolio summary (market value, cost, shares). Supports `amountMode: 'fixed' \| 'smart'` per segment. Smart mode calls Valuator to adjust investment amount. Depends on `IndexData` interface only. |
| **Valuator** | Pure function: `computeMultiplier(data, date, config): number`. Computes PE percentile over lookback window, maps to multiplier via two-threshold config (`cheapPercentile`/`cheapMultiplier`/`expensivePercentile`/`expensiveMultiplier`). Gold uses price percentile. Returns 1.0 when metric is unavailable. |
| **URL Serializer** | Bidirectional Strategy ↔ URL string. Round-trip stable. |

Four shallow modules (React components, no isolated testing):

| Module | Responsibility |
|--------|---------------|
| **Storage** | localStorage auto-save, JSON export/import, file drag-and-drop |
| **UI: ConfigPanel** | Segment editor cards (fixed/smart mode toggle, tier editor), fee inputs, eval window dates |
| **UI: ResultsView** | KPI cards, ECharts value vs cost chart (with optional PE auxiliary line), transaction detail table |
| **UI: DataExplorer** | Index comparison page: price vs total return chart + PE history chart with 30%/70% percentile lines |
| **App Shell** | Responsive layout (380px sidebar + flex content on desktop, stacked on mobile ≤768px), lifts all strategy state, tab navigation between simulator and data explorer |

State lives in App level, passed down as props. Strategy is the single source of truth — all derived values (cashflows, summary, XIRR) computed on the fly.

## Data Files

CSV files in `public/data/`, generated by `python3 scripts/fetch_data.py`. Stock indices have 3 columns: `日期,收盘价,市盈率`. Gold (AU9999) has 2 columns: `日期,收盘价`. PE data starts from ~2011; earlier rows have `nan` which Data Loader skips. Format: ISO 8601 dates, all trading days.

Running the fetch script: `python3 scripts/fetch_data.py` (incremental if files exist), `--full` (force redownload), `--verify` (validate only).
